# 忘却曲線 英単語（英検7級〜1級）

index.html をブラウザで開くと使えます（インターネット接続は不要）。

## ファイルの構成
- index.html / css/style.css / js/app.js … アプリ本体
- js/data/words_○.js … 級ごとの単語データ（7,6,5,4,3,p2=準2,2,p1=準1,1）
- data/words_master.json … 単語データの元（全級・テーマ・ふりがな入り）
- data/txt/○級英単語.txt … 元のtxtと同じ形式（#, 英語, 日本語, 品詞）で書き出したもの
- data/theme_overrides.tsv … テーマの手動修正
- build_web.py … words_master.json から js/data と data/txt を作り直すスクリプト

## 単語の追加・修正
1. data/words_master.json を編集（追加方法は build_web.py の冒頭に書いてあります）
2. python3 build_web.py を実行
3. ブラウザで Ctrl+F5

## データについて
- 元の9ファイル 15,247語 → 重複を1つにまとめて 9,893語 → 不足していた基本語 502語を追加 → 10,395語
- 同じ単語が複数の級にあった場合は、いちばん易しい級に入れています。意味は1つにまとめています。
- 6級・7級：元の2つのリストはほぼ同じ範囲でした。重なりをまとめた小学生レベルの語を、よく使う順に半分ずつ（7級＝より基本的な語、6級＝その次）に分けています。
- 品詞が空だった3,433語は、辞書データから推定した値です。
- テーマは、辞書データと日本語の意味から自動で分けたものです。ずれている語は theme_overrides.tsv で直せます。
- ふりがなは、3〜6級は元データの読みを使い、そのほかは辞書ソフトで自動生成しました（読み違いが残っている可能性があります）。
